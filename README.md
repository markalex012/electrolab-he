# מעבדת החשמל

אתר סטטי ללימוד חשמל ואלקטרוניקה בעברית.

כולל 12 שאלות עם הסברים, הדמיית חוק אוהם ואתגר מדע ומחשבים המביא שאלות באנגלית מ־Open Trivia DB באמצעות fetch ו־JSON. אין צורך בהתקנה, שרת או מפתח API.

## הפעלה
פתחו index.html בדפדפן, או הפעילו GitHub Pages מהענף main ותיקיית השורש.
